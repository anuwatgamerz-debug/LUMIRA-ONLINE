# LUMIRA ONLINE — Audio Licenses

## Current state

Every sound in the game right now is an **original placeholder generated by code in this repository**
(`public/audio-synth.js` for sound effects, the music / ambient synths in `public/audio.js`, recipes in
`public/audio-registry.js`). No third-party audio files are included, so there is nothing to attribute yet.

Downloading CC0 audio was attempted during development, but the build environment had no access to asset sites,
so no external files were added.

## Rules for adding audio

- Allowed: CC0, Public Domain, royalty-free / CC-BY with commercial use allowed, or audio made for LUMIRA.
- Not allowed: audio ripped from Ragnarok Online or any other game, or files with an unknown source.
- Every file added under `public/assets/audio/` gets a row below.

| filename | audioId | source URL | creator | license | attribution required |
|---|---|---|---|---|---|
| _(none yet)_ | | | | | |
