# LUMIRA ONLINE — Art Bible

ทุกภาพในเกม (ตัวละคร NPC อาคาร ต้นไม้ พร็อพ ไอเทม UI มอนสเตอร์) ต้องผ่านกติกาในเอกสารนี้
เป้าหมาย: **เห็นภาพไหนก็รู้ทันทีว่าเป็น LUMIRA**

ค่าตัวเลขทุกค่าในเอกสารนี้ใช้จริงในเครื่องมือสร้างภาพ `tools/art/` (palette, ขนาด, แสง, เส้นขอบ)
และถูกตรวจอัตโนมัติด้วย `tests/art.test.js` — ถ้าแก้ตัวเลขที่นี่ ต้องแก้ใน `tools/art/lumira_art.py` ด้วย

---

## 1. Art Style

- **Fantasy Pixel MMORPG** มุมมองบน 3/4 (top-down three-quarter) แบบ MMORPG คลาสสิก
- HD pixel art: 1 art pixel = 1 หน่วยภาพ วาดที่ความละเอียดเกม (ไม่ย่อ/ขยายภาพละเอียดสูงลงมา)
- น่ารักแต่ไม่เด็ก: สัดส่วนตัวละคร **3–3.5 หัว** (ไม่ใช่ chibi 2 หัว)
- รายละเอียดอ่านออกบนมือถือ: ทุกชิ้นส่วนที่สำคัญ (อาวุธ หมวก เสื้อ) ต้องกว้างอย่างน้อย 2 px
- ธีม Ancient Rune Fantasy: รูน ผลึก ทองอ่อน ฟ้าดวงดาว — ใช้เป็นจุดเน้น ไม่ใช่ทั้งภาพ
- โทนรวม: ผจญภัย มีชีวิต ไม่มืดหม่นเกินไป ไม่ neon

## 2. Perspective

- มุม 3/4 จากด้านบน: เห็นด้านหน้า (ทิศใต้) ของวัตถุและหลังคา/ด้านบนพร้อมกัน
- ทุก asset ใช้มุมเดียวกัน: ผนังด้านหน้าตั้งตรง หลังคาเห็นจากด้านบน ไม่มี vanishing point (ไม่มี perspective บิด)
- ตัวละครมี 4 ทิศ (N / W / S / E); W คือ E ที่กลับด้าน ระบบเตรียมช่องสำหรับ 8 ทิศไว้แล้ว (`dirs` ใน metadata)

## 3. Character Scale

| ค่า | ขนาด |
|---|---|
| Tile | 32 × 32 px |
| Frame ตัวละคร | 64 × 64 px, จุดยืน (pivot) ที่ (32, 58) ทุกเฟรม |
| ความสูงตัวละคร | 42 px (เท้าถึงยอดศีรษะ) + ผม 2 px ≈ 1.4 tile |
| ศีรษะ | 12 × 14 px → ตัวสูง ≈ 3.1 หัว |
| ไหล่ / สะโพก | 12 / 10 px (ชาย), 11 / 11 px (หญิง) |
| อาวุธ | ดาบ ≈ 16 px, ดาบใหญ่ ≈ 22 px, ธนู ≈ 20 px, คทา ≈ 26 px |

- เท้าอยู่ที่ y = 58 ในทุกเฟรม ยกเว้นท่าล้ม/นั่ง (ตรวจโดยเทสต์)
- Player และ NPC ใช้ base และ pixel density เดียวกัน 100%
- มอนสเตอร์ขนาดเล็ก ≈ 0.6–0.9 เท่าตัวละคร, ขนาดกลาง 1–1.3 เท่า, บอส 1.8–2.5 เท่า

## 4. Building Scale

| ค่า | ขนาด |
|---|---|
| ประตู | สูง 56 px = **1.33 เท่าตัวละคร**, กว้าง 24 px |
| หน้าต่าง | 16 × 18 px, ขอบล่างสูงจากพื้น 24 px |
| ผนังหน้า (1 ชั้น) | 72 px |
| ฐานหิน | 10 px |
| หลังคา | ยื่นจากผนัง 6 px, ความชันแสดงเป็นแถบหลังคา 3/4 |

- footprint ของอาคารเป็นจำนวน tile (เช่น 6×4) — แถวล่างสุดคือผนังหน้า (เดินผ่านไม่ได้) แถวบนเป็นหลังคา
- ภาพอาคาร: กว้าง = w × 32, สูง = h × 32 + 48 (หลังคายื่นขึ้นเหนือ footprint)
- ห้ามบ้านเตี้ยกว่า 2 เท่าตัวละคร ห้ามประตูเตี้ยกว่าตัวละคร

## 5. Tile Scale

- พื้นทุกชนิดอยู่บนกริด 32 px; ขอบระหว่างพื้นต่างชนิด (หญ้า↔ดิน, หญ้า↔หิน, ทราย↔น้ำ) **เป็นขอบนุ่มแบบสุ่มตาม noise** ไม่ใช่เส้นตรง
- ถนน (ดิน, หินปูพื้น), สะพานไม้, น้ำ, หน้าผาถ้ำ — สร้างจากชุดสีเดียวกันในตัวสร้างพื้น `genGround`
- ต้นไม้ ≥ 2.2 เท่าความสูงตัวละคร, พุ่มไม้ ≈ 0.5 เท่า, หญ้าสูง ≈ 0.3 เท่า

## 7. Lighting

- แสงหลักมาจาก **ด้านบนซ้าย**
- ทุกชิ้นส่วน: ขอบบน-ซ้าย = shade สว่าง, ขอบล่าง-ขวา = shade เข้ม, เนื้อใน = shade กลาง
- highlight จุดเล็ก (1–2 px) เฉพาะโลหะ ผลึก ตา
- ห้าม gradient นุ่มแบบภาพวาด — ใช้ระดับสีของ ramp เท่านั้น

## 8. Shadow

| วัตถุ | เงา |
|---|---|
| ตัวละคร / NPC / มอนเล็ก | วงรีนุ่มเล็กใต้เท้า (วาดโดย engine) |
| ต้นไม้ | วงรีใหญ่ เยื้องไปขวาล่าง |
| อาคาร | แถบเงาทิศขวาล่างที่ฐานผนัง |
| พร็อพ | เงาเล็กขวาล่าง |

- เงาอยู่ใน asset ได้เฉพาะ "เงาที่ตกบนตัวเอง"; เงาบนพื้นเป็นสีดำโปร่ง 25–30% ทิศขวาล่างเสมอ
- ห้าม asset มีเงา baked คนละทิศ

## 9. Character Classes

ทุกอาชีพใช้ร่างกายและโครงท่าทางเดียวกัน — เปลี่ยนเฉพาะ layer เสื้อผ้า/อุปกรณ์

| อาชีพ | ชิ้นที่บอกอาชีพ (class layer) | สีหลัก |
|---|---|---|
| Adventurer | tunic, เข็มขัดหนัง, รองเท้าบูต, กระเป๋าเล็ก ไม่มีสัญลักษณ์อาชีพ | น้ำตาล ครีม ฟ้าหม่น |
| Vanguard | tabard ฟ้าเข้มขลิบทอง, เกราะไหล่เหล็ก, โล่ | เทาเหล็ก ฟ้าเข้ม ทอง |
| Ranger | ผ้าคลุมไหล่+ฮู้ดสั้นสีป่า, กระบอกลูกธนูที่หลัง | เขียวป่า น้ำตาล ทองหม่น |
| Arcanist | ผ้าคาดเอวลายรูน, จี้ผลึกเรืองแสงเล็กน้อย, ปลายเสื้อคลุมยาว | ฟ้าเข้ม ม่วง ฟ้าดวงดาว |
| Cleric | ผ้าคลุมไหล่ไอวอรี่ สัญลักษณ์ทองศักดิ์สิทธิ์ (ไม่ใช่สัญลักษณ์ศาสนาจริง) | ไอวอรี่ ขาว ทองอ่อน ฟ้า |
| Rogue | ผ้าคลุมสั้นสีม่วงหม่น, เข็มขัดกระเป๋าหลายใบ | เทาเข้ม ม่วงหม่น น้ำตาล (ไม่ดำทั้งตัว) |
| Artisan | ผ้ากันเปื้อน, เข็มขัดเครื่องมือ, แว่นช่างบนหน้าผาก | น้ำตาล ทองแดง เหล็ก + teal |

- อาชีพขั้นที่ 2 = **วิวัฒนาการ** ของชุดเดิม (เพิ่ม cape / เกราะ / ลวดลาย) ห้ามเปลี่ยนสไตล์ เช่น Knight = Vanguard + ผ้าคลุมยาว + เกราะเต็ม, Berserker = Vanguard − โล่ + อาวุธใหญ่ + ขนสัตว์
- ห้ามคลาสใดตัวใหญ่กว่าคลาสอื่นเกิน 2 px

## 10. NPC Rules

- NPC ใช้ base เดียวกับผู้เล่น + ชุดตามหน้าที่ (outfit layer)
- Merchant: เสื้อกั๊กสีอุ่น ถุงเงิน · Blacksmith: ผ้ากันเปื้อนหนัง ถุงมือ · Healer: ชุดขาว-เขียว กระเป๋าสมุนไพร
  · Innkeeper: ผ้ากันเปื้อนผ้า · Guard: เครื่องแบบฟ้า + ตราเมือง + หมวกเหล็ก · Farmer: เสื้อผ้าหยาบ หมวกฟาง
  · Scholar/Mage: เสื้อคลุม · Elder: เสื้อคลุมยาวโทนหม่น · Citizen/Child: tunic สีต่างๆ
- **Quest NPC ไม่ต้องแต่งตัวพิเศษ** — ใช้ Quest Marker (❗ / ✓) เหนือหัวบอกแทน
- Class Master แต่งชุดอาชีพของตัวเองในระดับสูงสุดที่มีในเกม (class layer + cape ทอง) เป็นตัวอย่างที่ผู้เล่นอยากไปถึง
- NPC ยืนกระจายตามหน้าที่ ห่างกันอย่างน้อย 2 tile

## 13. Props

ชุดพร็อพพื้นฐาน (ทุก Region ใช้ทรงเดียวกัน เปลี่ยนวัสดุ): ถัง ลังไม้ กระสอบ เกวียน ม้านั่ง ตะเกียงถนน ป้าย รั้ว บ่อน้ำ
แผงตลาด เต็นท์ กองไฟ ชั้นวางอาวุธ ทั่ง ฟาง ธง รูปปั้น น้ำพุ — ขนาดอ้างอิงตัวละคร (ถัง ≈ 0.5 เท่า, เกวียน ≈ 1 เท่า, ตะเกียง ≈ 1.5 เท่า)

## 14. Equipment Layer

ลำดับการวาดตัวละคร (ทิศ S/E/W — ทิศ N สลับ back item ไว้ด้านหน้า):

1. Back item (ผ้าคลุม กระบอกลูกธนู) — ทิศ N วาดหลังสุดแทน
2. Base body (ผิว หน้า ชุดชั้นใน)
3. Hair (ผมช่วงหลัง)
4. Body armor (tunic / leather / chain / plate / robe ตามชนิดเกราะที่สวม)
5. Class layer (ชิ้นที่บอกอาชีพ)
6. Weapon (มือขวา) — ทิศ W วาดก่อนลำตัว
7. Shield / Off-hand (มือซ้าย) — ทิศ E วาดก่อนลำตัว
8. Headgear (stat)
9. Costume headgear (แทนที่ภาพ headgear ถ้าใส่)
10. Aura / Effect (engine)

- ทุก layer เป็น sprite sheet ขนาดเดียวกัน กริดเฟรมเดียวกัน pivot เดียวกัน → วางซ้อนได้ตรงทุกเฟรม
- Animation: Idle, Walk, Run (= walk เร็ว), Attack, Cast, Hit, Death, Sit, Interact
- ผมและผิวใช้สี key แล้ว engine เปลี่ยนสีตามที่ผู้เล่นเลือก
